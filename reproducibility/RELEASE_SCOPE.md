# Release scope and licensing

This public reproducibility release contains the source code, fixed numerical
inputs, model coefficients, deterministic point-set definitions,
machine-readable results, audit scripts, and focused tests associated with the
article *A Physics-Informed B-Spline Reconstruction of Flow Data*.

The MFA source trees are distributed under the `COPYING` notice included in
each tree. Bundled third-party components remain subject to their own license
notices under `third_party/` and the case-local optimizer directories. Unless a
separate license is explicitly stated, copyright in the remaining data,
scripts, and documentation remains with the respective rights holders.

The release contains author names and historical provenance records. It is a
curated research record rather than an anonymous submission archive or a copy
of every intermediate calculation performed during the study.
