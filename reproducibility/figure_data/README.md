# Figure-data extracts

These tables are unchanged, compact extracts from the completed manuscript
campaigns. They are included because the corresponding plot coordinates were
not all present in the earlier curated result subset.

- `one_d/strong_weight_candidates.tsv` contains the 26-row corrected
  strong-form beta sweep.
- `one_d/strong_weight_selection.tsv` contains the sealed, normalized Pareto
  geometry used to choose beta `3e-5`.
- `one_d/balance_histories.tsv` contains the seven 400-time figure series,
  including regional q=4 data for the four applicable spline models.
- `two_d_burgers/beta_selection.tsv`, `kappa_selection.tsv`, and
  `gamma_selection.tsv` contain the three plotted selection stages.
- `two_d_burgers/balance_histories.tsv` contains the seven series used in the
  regional q=4 and signed whole-domain q=1 panels.

The package-level `SHA256SUMS` file covers every table. Cavity figure tables
already reside with their archived result records and are therefore not
duplicated here.
